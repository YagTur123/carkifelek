# 3D Casino & Şans Oyunları Platformu

PeerJS (WebRTC), Canvas, CSS 3D Perspektif Fiziği ve Web Audio API ile geliştirilmiş, 8 farklı 3D kumarhane oyunu içeren eğlenceli ve hileli seçim sistemi.

## 8 Farklı 3D Oyun Modu
1. **3D Casino Çarkı (3D Wheel)**: 24 derece eğimli 3D perspektif, pirinç perçinler ve ibre yaylanması.
2. **3D Vegas Slots**: 3 makaralı 3D silindir (drum), mekanik kol ve overshoot yaylanma fiziği.
3. **3D Rulet Masası (3D Roulette)**: Çarkın içinde dönüp ceplere seken rulet topu.
4. **3D Plinko Board**: Eğimli perspektif, melodik pentatonik çan sesleri ve parlayan pirinç çiviler.
5. **3D Casino Zarları (Craps)**: Masaya fırlatılan, havada dönüp yuvarlanan gerçek 3D küp zarlar.
6. **3D Gizemli Kart Masası (Card Flip)**: Krupiyenin masaya kapalı dağıttığı ve havada 180° dönerek açılan 3D poker kartları.
7. **3D Yazı - Tura (Coin Toss)**: Havada taklalar atarak masaya şangırdayan 3D altın sikke.
8. **3D Aviator Roket Oyunu (Crash)**: Yükselen çarpan (`1.00x... 4.50x...`), gerilim ve kazanan fırlatması.

## Özellikler
- Kumandadan 8 oyun arasında tek tıkla canlı geçiş.
- Tüm oyunlarda kusursuz çalışan uzaktan gizli hedef (kurban) seçimi.
- Web Audio API ile canlı sentezlenen gerçekçi SFX motoru ve kamera sarsıntısı.
- Otomatik açık masa keşfi (Lobi) ve kamera ile QR bağlantısı.
- Çekiliş tarihçesi / log ve kazananı eleme modu.
